# rypsok-core

The core library of [rypsok](https://github.com/nabbisen/rypsok), a headless
meta-search service for AI agents. It holds the models, the search and fetch
pipelines, the engine drivers and the policies, and depends on no protocol
SDK. The binary crate `rypsok` wraps it with the MCP adapters and the command
line.

The interface is unstable until release 1.0.0.
