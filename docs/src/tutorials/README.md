# Tutorials

Five tutorials in the order you will meet the features. Each says what
you will have at the end, what you need, the exact steps, what you
should see, and what to do if you do not. Every file and call shown is
kept in the repository's `examples/` directory and checked by the
project's CI, so what you see here is what rypsok does.

1. [Your first search](./01-first-search.md): run rypsok, make one call
   by hand, read the answer, connect a runtime. Ten minutes, no key.
2. [A keyed engine](./02-keyed-engine.md): add Brave Search with a key
   kept out of the file; see what `engine_status` tells you.
3. [Reading a page](./03-reading-a-page.md): `web_fetch`, its budgets,
   reading a long page in parts, and the answers a page can give.
4. [Network mode](./04-network-mode.md): HTTP behind a proxy, callers
   and tokens, the headers every request carries.
5. [The scraping switch](./05-scraping.md): a keyless general engine and
   what you accept to use it.
